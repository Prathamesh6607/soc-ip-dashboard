SOC IP Dashboard - Nginx Hosting Steps
======================================

Project root:
/home/prathameshpendkar/Desktop/soc_ip_dashboard

-------------------------------------------
0) One-time Nginx setup (recommended)
-------------------------------------------

# One-time: make launcher executable
cd /home/prathameshpendkar/Desktop/soc_ip_dashboard
chmod +x setup_nginx_host.sh run_dashboard_nginx.sh

# Run setup as root (domain is optional; default is "_")
sudo bash ./setup_nginx_host.sh localhost

# Or double-click Linux launcher file
# SOC-IP-Dashboard.desktop

# This will:
# - Create systemd service: soc-ip-dashboard
# - Configure nginx reverse proxy
# - Host dashboard on port 80

-------------------------------------------
1) Start / restart hosted dashboard
-------------------------------------------

cd /home/prathameshpendkar/Desktop/soc_ip_dashboard
./run_dashboard_nginx.sh

Open:
http://localhost

-------------------------------------------
2) Manual service commands
-------------------------------------------

sudo systemctl status soc-ip-dashboard
sudo systemctl restart soc-ip-dashboard
sudo systemctl restart nginx
sudo journalctl -u soc-ip-dashboard -f

-------------------------------------------
3) App dependency setup (if not done)
-------------------------------------------

# Go to project root
cd /home/prathameshpendkar/Desktop/soc_ip_dashboard

# Create virtual environment (skip if already created)
python3 -m venv venv

# Activate venv
source venv/bin/activate

# Install project dependencies
pip install -r soc_ip_governance/requirements.txt

# Configure AbuseIPDB key (required)
# Edit file: soc_ip_governance/config.ini
# Set:
# [abuseipdb]
# api_key = YOUR_ABUSEIPDB_API_KEY

-------------------------------------------
4) Quick troubleshooting
-------------------------------------------

- Check Streamlit backend port:
  ss -ltnp | grep 8501

- Validate nginx config:
  sudo nginx -t

- If site is not reachable:
  sudo systemctl status nginx soc-ip-dashboard
  sudo journalctl -u soc-ip-dashboard -n 100
